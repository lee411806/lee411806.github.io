# 인증 및 사용자 관리

## 토큰 종류

### 1. 서비스 연동 토큰 (API 토큰)
- 노션, 구글 캘린더, 젠킨스 등 각 서비스와 연동하는 키
- 서비스별로 발급

### 2. 사용자 인증 토큰 (로그인 토큰)
- MCP 서버에 접근하는 사용자가 누구인지 식별
- 사용자마다 발급 (JWT 등)
