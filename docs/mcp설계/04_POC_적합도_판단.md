# POC 적합도 판단

## 연동 대상별 평가

| 서비스 | API 난이도 | POC 적합도 | 이유 |
|--------|-----------|-----------|------|
| 노션 | 쉬움 | ★★★ | API 간단, 이미 연동 경험 있음 |
| 구글 캘린더 | 보통 | ★★★ | OAuth 있지만 문서 잘 되어있음 |
| Slack | 쉬움 | ★★★ | Bot 토큰 하나면 바로 가능 |
| GitLab | 보통 | ★★ | API 토큰 발급 필요, 사내 권한 확인 필요 |
| Jenkins | 보통 | ★★ | 사내 인프라팀 협조 필요 |
| NAS | 어려움 | ★ | 네트워크/마운트 설정 복잡 |

## POC 추천 순서

1. 노션 — 이미 경험 있음, 빠르게 검증 가능
2. Slack — Bot 토큰 하나면 바로 가능
3. 구글 캘린더 — 문서 잘 되어있어 구현 수월

## 후순위 (리스크 있음)

- Jenkins, GitLab → 사내 인프라팀 협조 필요, POC 후반부로 미룰 것
- NAS → 네트워크/마운트 설정 복잡, 마지막에 검토
