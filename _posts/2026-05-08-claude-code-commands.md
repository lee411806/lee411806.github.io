## 1. 설정 관련 (환경 제어)

- `/config` → 전체 설정 (모델, 권한, 테마 등)
- `/model` → 모델 변경 (작업 난이도에 따라 선택)
- `/allowed-tools` → 파일/명령 실행 권한 관리 (보안 핵심)

---

## 2. 작업 효율 관련 (실무 핵심)

- `/help` → 명령어 목록 확인
- `/clear` → 대화 초기화 (컨텍스트 리셋)
- `/compact` → 대화 요약 (토큰 최적화)
- `/status` → 현재 상태 확인 (모델, 사용량 등)
- `/cost` → 비용/사용량 상세 확인

---

## 3. 필수 키보드 단축키

- `Ctrl + C` → 현재 작업 즉시 중단
- `Shift + Enter` → 줄바꿈 (여러 줄 입력)
- `↑ / ↓` → 이전 명령 불러오기
- `Ctrl + B` → 백그라운드 실행 (멀티태스킹)

---

## 4. 고급 활용 명령어

- `/test` → 테스트 실행 + 실패 수정 + 커버리지 + 커밋 자동화
- `/ide` → IDE 연동 (diff 확인, 코드 리뷰)
- `/mcp add / list / remove` → 외부 서비스 연동 (DB, GitHub, AWS)
- `/terminal-setup` → 터미널 환경 최적화

---

## 5. 실전 활용 팁

- **프롬프트 구체적으로 작성** → 결과 정확도 향상
  - ❌ 로그인 만들어줘
  - ✅ JWT 기반 로그인 API 만들어줘 (/api/auth/login, 토큰 반환)

- **`CLAUDE.md` 활용** → 프로젝트 컨텍스트 자동 제공 (DB, 실행 명령어 미리 정의)
- **백그라운드 작업 (`Ctrl + B`)** → 긴 작업 병렬 처리
- **파일 드래그 앤 드롭** → 파일 입력 자동화
- **이미지 붙여넣기 (`Ctrl + V`)** → UI/이미지 기반 작업 가능

---

## 6. 주의사항

- **메모리 관리** → CLAUDE.md / 문서화 필수
- **토큰 관리** → `/compact`, `/clear` 활용
- **권한 설정** → 프로덕션에서는 제한 필요 (`/allowed-tools`로 bash 제한)
- **결과 검증** → AI 결과 반드시 직접 확인 (인증/보안 코드 직접 리뷰)
