## 에이전트(Agent)란?

> **에이전트 = 스스로 판단하고 행동하는 AI**
> 에이전트 개념의 핵심: **"목표만 주면 스스로 판단해서 실행"**

## 일반 AI vs 에이전트 AI

| | 일반 AI (ChatGPT 등) | 에이전트 AI |
|---|---|---|
| **방식** | 질문하면 답변만 함 | 스스로 계획 세우고 실행 |
| **행동** | 텍스트 출력만 | 파일 열기, 코드 실행, 브라우저 제어 등 |
| **개입** | 매번 사람이 입력 | 목표만 주면 알아서 진행 |

**예시: "로깅 기능 만들어줘"**

- 일반 AI → 코드 작성해서 보여줌, 직접 복붙해야 함
- 에이전트 → 파일 직접 열고, 코드 작성하고, 테스트 실행하고, 오류 나면 스스로 고치고, 완료까지 혼자 함

## 하네스 vs Antigravity 에이전트 비교

같은 에이전트 개념이지만 **권한 범위**가 다름

| | 하네스 에이전트 | Antigravity 에이전트 |
|---|---|---|
| **할 수 있는 것** | 코드 탐색, 검색, 파일 읽기/수정 | 터미널 실행, 브라우저 제어, OS 레벨 접근 |
| **자율도** | 사람이 승인 단계 있음 | 거의 완전 자율 |
| **보안** | 샌드박스 안에서 제한적 | 제한 거의 없음 → 취약점 |

## 스킬(Skill)도 보조 개념으로 유사함

- **하네스 스킬** = "이런 상황에 이렇게 행동해" 라는 **사전 정의된 행동 패턴**
- **Antigravity** 도 에이전트한테 역할/행동 방식을 부여하는 게 동일한 원리

즉 하네스가 **안전하게 제한된 에이전트 시스템**이라면, Antigravity는 **제한을 풀어버린 에이전트 시스템**
