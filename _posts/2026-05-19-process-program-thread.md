## 프로그램 (Program)

- 디스크에 저장된 **실행 가능한 파일** (정적인 상태)
- 아직 실행되지 않은 코드 덩어리

## 프로세스 (Process)

- 프로그램이 **메모리에 올라가 실행 중인 상태** (동적인 상태)
- OS가 자원(메모리, CPU, 파일)을 할당해줌
- 각 프로세스는 독립된 메모리 공간을 가짐

## 스레드 (Thread)

- 프로세스 안에서 **실제로 실행되는 작업 단위**
- 하나의 프로세스는 여러 스레드를 가질 수 있음
- 같은 프로세스의 스레드들은 **메모리(Heap)를 공유**

## 관계 정리

```
프로그램 (파일)
    ↓ 실행
프로세스 (메모리 할당)
    ↓ 분기
스레드 1 | 스레드 2 | 스레드 3  ← Heap 공유
```

| 구분 | 프로그램 | 프로세스 | 스레드 |
|---|---|---|---|
| 상태 | 정적 | 동적 | 동적 |
| 메모리 | 디스크 | 독립 공간 | 공유(Heap) |
| 단위 | 파일 | 실행 단위 | 작업 단위 |

> 스레드가 Heap을 공유하기 때문에 동시성 문제가 발생한다
