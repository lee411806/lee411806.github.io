### 토큰 종류

MCP 서버에서 토큰은 두 종류가 필요하다.

**1. 서비스 연동 토큰 (API 토큰)**
- 노션, 구글 캘린더, 젠킨스 등 각 서비스와 연동하는 키
- 서비스별로 발급

**2. 사용자 인증 토큰 (로그인 토큰)**
- MCP 서버에 접근하는 사용자가 누구인지 식별
- 사용자마다 발급 (JWT 등)

---

### 사용자별 서비스 연동 관리

사용자마다 어떤 서비스에 연동되어 있는지 제어 필요.

| 사용자 | 연동 서비스 |
|--------|------------|
| 사용자 A | 노션, 구글 캘린더 |
| 사용자 B | 젠킨스, 노션 |

사용자별로 어떤 서비스 토큰을 갖고 있는지 관리하는 테이블 필요.

---

### 전체 흐름

```
회원가입 → 로그인 → JWT 발급
                      ↓
              JWT로 내가 누구인지 증명하면서
              노션 API 키 등록 → DB 저장
              Slack 토큰 등록 → DB 저장
              구글 캘린더 등록 → DB 저장
```

JWT는 "내가 누구인지", API 키들은 "내가 어떤 서비스에 연동됐는지"를 증명한다.

각 서비스마다 따로 발급받아서 등록해야 하며, 관리자 페이지에서 아래와 같은 형태로 관리한다.

```
[연동 서비스 관리]
노션        [ API 키 입력 ]      ← 노션에서 발급
Slack       [ Bot 토큰 입력 ]    ← Slack에서 발급
구글 캘린더  [ Google 로그인 ]   ← OAuth 인증
```
