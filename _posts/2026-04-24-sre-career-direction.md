## SRE란?

> 백엔드 코딩 실력으로 서버 운영 문제를 자동화해서 푸는 사람

## 실제 업무 예시

**1. 모니터링 시스템**
서버 CPU/메모리 임계치 넘으면 → 슬랙으로 알람 오는 봇 만들기

**2. 자동 복구 스크립트**
특정 서비스 죽으면 → 자동으로 재시작하는 프로그램

**3. 배포 안정성 툴**
배포할 때 트래픽 조금씩 올리면서 → 에러율 모니터링하다가 터지면 자동 롤백

**4. 장애 분석 툴**
로그 수천만 줄 중에서 → 장애 원인 패턴 찾아주는 분석기

## 기술 스택

| 역할 | 기술 |
|---|---|
| 자동화 스크립트 | Python, Go |
| 모니터링 | Prometheus, Grafana |
| 서버 오케스트레이션 | Kubernetes |
| 인프라 코드화 | Terraform |

## 백엔드와 다른 점

| | 백엔드 | SRE |
|---|---|---|
| 만드는 것 | 비즈니스 기능 (게시글 CRUD 등) | 서비스 운영을 위한 내부 툴 |
| 대상 | 사용자 | 개발팀 |
| 목표 | 기능 구현 | 서비스 안정성 |

## 나의 커리어와 연결

- 헥사고날/DDD → 서비스 코드 이해도 (장애 원인 파악 빠름)
- Kotlin/Spring → 회사 서비스 코드 읽기 가능
- AI 휘두르기 → AI 기반 장애 탐지/자동화 (AI SRE)
