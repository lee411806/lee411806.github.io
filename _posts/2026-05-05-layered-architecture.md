### 🏗️ 4계층 아키텍처의 핵심 역할 (4줄 요약)

1. **Presentation Layer**: 사용자의 요청을 받고 응답을 돌려주는 UI 및 API의 입출력 창구 역할을 합니다.
2. **Application Layer**: 도메인 객체들을 조립하여 비즈니스 로직의 전체적인 흐름을 제어하고 트랜잭션을 관리합니다.
3. **Domain Layer**: 시스템의 심장부로, 프레임워크나 외부 기술에 의존하지 않는 순수한 비즈니스 규칙을 정의합니다.
4. **Infrastructure Layer**: DB 연동, 외부 API 호출 등 실제 기술적인 세부 구현을 담당합니다.

---

### 💭 회고: 모듈을 나누고 체감된 변화

가장 확실하게 체감되었던 부분은 **테스트 코드 작성이 매우 간편해졌다**는 점입니다.

특히 **도메인(Domain)** 계층을 순수하게 분리하니, 무거운 프레임워크나 DB 의존성 없이도 핵심 로직을 빠르고 정확하게 검증할 수 있었습니다. 이전의 복잡하게 얽혀 있던 프로젝트를 테스트할 때 느꼈던 피로감이 사라지고, 구조의 명확함이 주는 이점을 직접 경험할 수 있었던 유익한 시간이었습니다.
