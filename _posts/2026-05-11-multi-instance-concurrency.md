### 1. 동시성 문제의 본질

공유 자원에 동시에 접근해서 생기는 것

---

### 2. 동시성이 일어나는 레벨

- 레벨 1 - 멀티 인스턴스 : 프로세스(JAR) 여러 개
- 레벨 2 - 멀티 스레드 : 하나의 JAR 안에서 스레드 여러 개
- 레벨 3 - 비동기(async) : 하나의 스레드 안에서 번갈아 처리

---

### 3. 인스턴스 = JAR 하나

같은 프로그램이지만 포트 다름 → 프로세스 분리 → 메모리 분리

```bash
java -jar app.jar --port=8080  # 인스턴스 1
java -jar app.jar --port=8081  # 인스턴스 2
```

---

### 4. 멀티 인스턴스 + 로드밸런싱 구조

```
유저 요청
    ↓
[로드밸런서]
   ↙    ↘
JAR 1   JAR 2   ← 메모리 완전 분리
   ↘    ↙
   [DB]          ← 공유 자원 (문제 발생 지점)
```

---

### 5. 왜 문제가 생기냐

- 싱글 인스턴스 → 코드 안에서 Lock으로 해결 가능
- 멀티 인스턴스 → JAR끼리 메모리 공유 안 됨 → DB는 여전히 공유 → 서버 경계를 넘는 동시성 문제 발생
