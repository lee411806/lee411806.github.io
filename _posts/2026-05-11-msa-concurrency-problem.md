### 핵심 본질

> 공통 자원 + 동시 접근 = 동시성 문제

레이어만 다를 뿐 본질은 항상 같다.

---

### 동시성 문제가 생기는 상황 3가지

**상황 1. 같은 서비스 멀티 인스턴스**

```
JAR 1 ──→ ┐
           DB  ← 공통 자원
JAR 2 ──→ ┘
```

**상황 2. MSA에서 다른 서비스들이 같은 자원 접근**

```
주문 서비스 ──→ ┐
                재고 DB  ← 공통 자원
결제 서비스 ──→ ┘
```

**상황 3. 하나의 서비스 안에서 멀티 스레드**

```
스레드 1 ──→ ┐
              공유 변수  ← 공통 자원
스레드 2 ──→ ┘
```

---

### 트랜잭션이 있어도 왜 문제가 생기냐

각 트랜잭션은 개별적으로 보장되지만, 동시에 같은 자원에 접근하면 문제 발생.

```
트랜잭션 A: 재고 읽음 → 1개 있음
트랜잭션 B: 재고 읽음 → 1개 있음   ← A가 아직 커밋 안 한 사이에
트랜잭션 A: 주문 처리 → 재고 -1 → 커밋
트랜잭션 B: 주문 처리 → 재고 -1 → 커밋  ← 이미 0인데 또 차감
```

각 트랜잭션은 자기 입장에선 정상 → 근데 결과는 재고 -1

→ 이게 **격리 수준(Isolation Level)** 문제
