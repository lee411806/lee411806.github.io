```
[레벨 1] 멀티 인스턴스  ← 프로세스(JAR) 여러 개
           ↓
[레벨 2] 멀티 스레드   ← 하나의 JAR 안에서 스레드 여러 개
           ↓
[레벨 3] 비동기(async)  ← 하나의 스레드 안에서 번갈아 처리
```

| 레벨 | 단위 | 공통 자원 |
|---|---|---|
| 멀티 인스턴스 | 프로세스 | DB, Redis |
| 멀티 스레드 | 스레드 | 메모리(변수) |
| 비동기 | 작업 단위 | - |

> 레이어마다 공통 자원이 다르고, 해결 방법도 다르다
